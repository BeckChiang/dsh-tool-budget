# dsh-tool-budget

给 DeepSeek Harness 加一块**会话级工具预算**面板：先挑一个方案（预设 / 你自己保存的 / 学习中得到的），再把不符的部分在工具列表里改掉；关掉的工具从模型看到的工具清单里消失，省下的是每一轮都要付的 token。

面板挂在输入框正下方的 `⚙ 工具预算` 胶囊里，只对当前会话生效，下一次请求就按新清单走。

## 它解决什么

- **省每轮 token**：工具清单每轮都要随提示词发送，关掉一个组就少发一组工具定义。
- **提高命中**：几十上百个工具里，当前任务用不到的会稀释注意力；按方案收窄后模型更容易选对。
- **可回退**：关错了在面板里一键恢复，或者切回「全部保留」。

代价只有一处：切换工具清单会让提示词前缀失效一次，那一刻要重付上下文的输入费用。面板会在真正需要重付时把数字写在成本卡上，平时不打扰。

## 安装

插件市场：搜索 `dsh-tool-budget` 安装。本地开发用软链接：

```
plugin_manager install_bundle target="link:C:/Users/recko/DSH/plugins/dsh-tool-budget"
```

装完刷新页面，输入框下方出现 `⚙ 工具预算`。改了 Host 半侧（`index.js` / `lib/*.js`）要重挂：`set_plugin target="include:dsh-tool-budget"` 先 `enabled=false` 再 `true`。

## 面板怎么用

自上而下四块，顺序就是使用顺序：

1. **成本估算**（默认展开）——省下 / 常驻 / 重付 / 净省，加一行「切换后每轮约多少」和红色阈值。参数可展开微调（五个），说明写在每项后面。
2. **方案**——分三组折叠：
   - **预设**：内置的方案（全部保留、只留基础、代码 + 文件、查资料 + 网页、图像 + 设计、办公文档）。
   - **用户保存**：你存下来的方案；点勾选先选进组合，顶部「应用这组」生效；每行可改名、可删除。
   - **学习候选**：从历史对话里学到、还没采用的组合。候选不能勾选，先点「采用」才变成普通方案。
   - 组合与当前不一致时，成本卡会显示「应用后重付 N token 一次」；一致时按钮直接禁用。
3. **工具列表**（按频率排序，组与插件两种视图）——每组三个胶囊 `开 N / 降 M / 关 K`；每行三档开关、参数签名、调用次数徽章。改动会进入「未写回」状态，顶部出现 `保存改动 / 放弃改动`。
4. **本轮学习**（在方案区下方）——对话满 N 轮（默认 3，可改）后，按当前会话给出「关掉没人用的组」和「恢复被拦下的组」，点一下直接生效。

底部常驻一行状态：学习进度、本轮改动提示。

## 方案的来源与生命周期

| 来源 | 谁创建 | 可否改名/删除 | 应用方式 |
| --- | --- | --- | --- |
| 预设 `preset` | 插件内置 | 否 | 勾选后应用 |
| 用户保存 `saved` | 你（存为方案 / 「保存改动」另存） | 可以 | 勾选后应用 |
| 学习候选 `learned` | 插件从历史对话聚类 | 先「采用」转成用户方案，之后可改可删 | 不能直接勾选 |

- **写回**：当前会话已经挂在某个「用户保存」的方案上时，在工具列表里做精细调整，顶部提示「已改动 N 处」，点保存就把调整写回那个方案（其它会话共享同一份）；当前是预设或没有方案时，只能「另存为新方案」。
- **查重**：另存时按「隐藏了哪些工具」算哈希，和目标方案完全一致就提示已存在，确认后才会再存一份。
- **学习只建议、不自动建**：学习结果先以候选形式出现，采用前不会出现在可应用列表里，也不会自动生效。

## 成本估算

四个输入：

- 隐藏工具定义的字符数（只算真从清单里拿掉的部分）
- 当前上下文 token 数（会话日志里最近一次 `usage` 的 `input + cacheRead`）
- 工具块自身 token 数（同样来自日志）
- 历史平均每轮 token（日志 `usage` 均值）

公式：

```
省下的   saved = 隐藏工具字符数 ÷ charsPerToken
首次重付 repay = (上下文 − 工具块) × missFactor
净省     net   = saved − 常驻开销
切换后   projected = 平均每轮 − saved + 常驻
```

- 常驻开销是模式说明本身的固定成本：auto 200、ask 20、不使用 0，用户不可改。
- 红色阈值：`平均每轮 × thresholdMultiplier`，重付超过它就标红。
- 误差：字符数 ÷ 3.6 只是近似；`usage` 缺失时退回按字符估算并标 `estimated`。

可改参数（面板「参数」）：`charsPerToken` 3.6、`missFactor` 1、`thresholdMultiplier` 2、`priceInput` 2、`priceCache` 0.2。

## 三档级别

| 级别 | 模型看得见 | 能调用 | 用途 |
| --- | --- | --- | --- |
| `normal` | 是 | 是 | 正常 |
| `warn` 降权 | 是 | 否，返回拒绝原因 | 保留线索但劝退 |
| `hidden` 隐藏 | 否 | 否 | 真正省 token |

两条硬规则：`tool_budget` / `present` / `ask_user_question` 永远是 normal；读文件、写文件、命令执行这类受保护工具允许关，但要再确认一次。

## 三种模式

| 模式 | 行为 | 常驻 |
| --- | --- | --- |
| `auto` | 模型自己看到「被挡下的组」并主动恢复 | 200 |
| `ask` | 模型停下来告诉你缺哪个能力，你点一下恢复（默认） | 20 |
| `off` 不使用 | 插件完全不生效，工具全部原样，连 `tool_budget` 都不注册 | 0 |

## 调用次数

三个口径：本会话 / 近 30 天 / 全局。数据来自 `~/.dsh/sessions/**/session.v4.jsonl.zstd`，按文件大小 + mtime 增量缓存到 `~/.dsh-tool-budget/usage-cache.json`，首次全量扫约 5 秒，之后命中缓存几十毫秒。

次数只进面板，不进提示词——所以它不会破坏前缀缓存，也不会影响模型的判断。

## 数据文件

- `~/.dsh-tool-budget/budget.json`：偏好、方案、每个会话的级别与选择
- `~/.dsh-tool-budget/usage-cache.json`：调用次数缓存
- `~/.dsh-tool-budget/learning.json`：学习候选与采用记录

## 工具、命令与接口

- 工具：`tool_budget`（`action` = list / on / off / warn / reset / profile / pack / cost，`target` 支持 `all`、组、插件、前缀、通配）
- 命令：`/budget list|reset|all on|all off|on <t>|off <t>|warn <t>`
- HTTP：`/tool-budget/state`（GET 需 `?session=`，POST 是各种 op）、`/usage`、`/cost`（POST 预览切换成本）、`/learning`、`/preferences`

## 边界

- 只在会话作用域生效，没有全局默认；预设/agent 作用域注册的工具（如 `ops_discover_tools`）关不掉，面板标「会话固定」。
- 学习是从本地会话日志离线聚类，不是在线模型判断；样本不足时只给候选不给结论。
- 重付只发生一次，但切换次数越多累计越贵——尽量在任务开头定好方案。
- 中英文切换即时生效；工具描述的变化从下一条消息起生效。
